# Task Tracker CLI

This is a command-line interface task tracker. 

## How to use
- `add <description>`: Adds a new task
- `update <id> <description>`: Updates a task
- `delete <id>`: Deletes a task
- `mark_progress <id>`: Marks a task as in-progress
- `mark_done <id>`: Marks a task as done
- `list <status>`: Lists tasks by status
